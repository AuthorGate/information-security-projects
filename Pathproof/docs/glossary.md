# PathProof glossary

Each term includes a one-sentence definition and an analogy.

| Term | Meaning | Analogy |
|---|---|---|
| S3 bucket | A bucket is a named container for stored objects in Amazon S3. | A labelled filing cabinet. |
| Object | An object is one stored item identified by a key within a bucket. | One folder retrieved using its filing label. |
| Canary | A canary is a harmless planted item with known contents used to test one specific access claim. | A labelled test parcel used to check the delivery route. |
| Snapshot | A snapshot records the configuration facts collected within a stated scope at one time. | A dated photo of the switches on a control panel. |
| Coverage | Coverage records which observations were actually collected and where evidence is missing. | An inspector marking which rooms were accessible. |
| Finding | A finding records one check's conclusion and the facts supporting it. | One inspection note with its photograph attached. |
| MANUAL | MANUAL means the check lacks enough usable evidence to decide. | An inspector marking a locked room for a return visit. |
| ACL | An access control list records which users or groups have specified permissions on an item. | A guest list at a door. |
| Public-access block | A public-access block setting restricts particular ways public S3 permissions can be granted or used. | A building rule that limits when a guest pass works. |
| Loopback | Loopback is the network route from a computer back to itself. | An internal phone extension that never leaves the building. |
| Port | A port directs a network connection to a particular listening service. | An extension number for one office. |
| Moto | Moto is a testing library that can answer AWS-shaped requests on a local server. | A practice checkout till used for staff training. |
| Authorization gate | An authorization gate decides whether a named actor is permitted to attempt a specified operation. | A librarian checking a borrowing card before handing over a book. |
| Unsigned request | An unsigned request supplies no AWS signature to authenticate an AWS identity. | A visitor asking for a public leaflet without showing ID. |
| Digest | A digest is a fixed-length value computed from bytes to check whether they match an expected value. | Comparing the recorded fingerprint of a specimen. |
| IAM principal | A principal is an identity to which an access decision can apply. | The person named on a building pass. |
| Policy simulator | The AWS policy simulator evaluates a proposed permission request without carrying out the service operation. | Asking the access office to review a badge on paper. |
| Conformance | Conformance here measures how often two decision systems agree on the same supported cases. | Two examiners marking the same set of answers against the same rubric. |
| Fixture | A fixture is a deliberately prepared example with known facts used in a test. | A driving course with a marked stopping point. |
| CIS mapping | A CIS mapping links a check to a numbered requirement in a named benchmark version. | An inspection form citing a particular paragraph of a building code. |
| ATT&CK ID | An ATT&CK ID identifies a documented adversary behavior that can provide context for a scenario. | A catalogue number pointing to a description in a reference book. |
| Graph edge | An edge records a specific relationship justified by inventory facts. | A route on a map with a label explaining what the road carries. |
| Crown jewel | A crown jewel is a resource the lab explicitly identifies as important to protect. | A museum naming its most important exhibit. |
| Mutelist | A mutelist records which findings to hide from a named report view. | Folding an acknowledged item on a checklist while keeping its record. |
| Precision | Precision is the fraction of reported failures that correspond to labeled bad examples. | The fraction of sounding alarms that were genuine alarms. |
| Recall | Recall is the fraction of labeled bad examples the check detects. | How many of the hidden defects an inspector actually finds. |
| Risk multiplier | A risk multiplier adjusts the priority of a route for a stated condition. | Increasing an inspection priority when a warning light is out. |
| Saved plan | A saved plan fixes the actor, target and sequence of observations for a repeated experiment. | Running the same acceptance test on a bicycle before and after repair. |
| Business assertion | A business assertion is a named expected operation that must continue to work after a fix. | A staff badge still unlocking the staff door after guest access is removed. |
